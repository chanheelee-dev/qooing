# 규칙

* **파일명**: `YYYY-MM-DD-<feature-name>.md`. 기존 `NN-<feature>.md` 문서는 안정성을 위해 유지한다.
* **index 갱신**: 새 spec을 추가하면 위 목록에 링크와 한 줄 설명을 추가한다.
* **discoverability**: 이 디렉토리에는 항상 `index.md`를 둔다.
